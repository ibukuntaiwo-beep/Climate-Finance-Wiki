# Context-Control Rules

When exploring or editing the wiki, control context noise:

1. Do not read large files unless absolutely required. Prefer reading only the sections needed.
2. Use `wiki-status.json` to understand the current article inventory before scanning the `wiki/` folder.
3. Use `_index.md` files as the entry point for understanding what exists under a topic — do not glob the full folder unless `_index.md` is outdated.
4. If a search returns too many results, narrow the query before continuing.
5. Prefer small, targeted edits. Avoid large mixed changes in one step.
6. Summarise findings before taking the next action to keep working context clean.
7. When processing raw material, do not load all raw files at once. Process one source at a time unless the task explicitly requires cross-source synthesis.
