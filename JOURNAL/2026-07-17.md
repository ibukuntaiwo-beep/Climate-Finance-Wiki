**Design decisions:**
- All four options are semi-minimalist reductions of the current 9-section homepage: hero + featured case + category index + trails + news + one credibility/author line.
- Imagery re-curated away from disaster stock (wildfire house) toward capital/infrastructure: dark glass towers (`photo-1486406146926`), aerial solar farm (`photo-1497435334941`), pylons at dusk (`photo-1473341304170`) — all visually verified. Note: the old homepage's `photo-1473341304170` alt text says "wind turbines" but the photo is transmission pylons.
- All mockups: single accent color, no pure black, no Inter, prefers-reduced-motion guards, transform/opacity-only animation, live-site links.

**Verification:**
- Desktop (1440px) visually reviewed via headless Edge screenshots — all four clean.
- Mobile: initial 390px screenshots suggested overflow, but four independent agent audits (CDP `Emulation.setDeviceMetricsOverride` at 320/390/768px, fonts loaded and blocked) proved the files clean — the apparent clipping was a headless-Edge artifact (OS clamps window width to ~492px minimum). Options 1 and 3 received defensive `min-width:0` / `minmax(0,1fr)` hardening inside existing mobile media queries; zero visual change confirmed by before/after bounding-box comparison.
